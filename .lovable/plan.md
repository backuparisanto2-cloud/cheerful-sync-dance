# Import sync-happy-sparkle into this project

The repo is a public Lovable project (TanStack Start + Tailwind + Cloud backend): an inventory/expense app for a kost/property with pages for rooms (`/kamar`, room detail), facilities (`/fasilitas`), expenses (`/pengeluaran`), and reports (`/laporan`), plus photo/attachment uploads and PDF/Excel export.

## What I'll do

1. Copy the repo's app code into this project: routes, components (including the shadcn UI set), hooks, lib, assets, styles, router/server bootstrap.
2. Install the extra dependencies it needs (jspdf, xlsx, pdfjs-dist, recharts, sonner, radix packages, etc.).
3. Enable Lovable Cloud for this project (the app needs a database, auth and file storage).
4. Re-apply the repo's 8 database migrations here so tables, RLS policies and storage buckets exist, adjusted if needed for grants/policies.
5. Wire the generated backend client/auth files to this project's own backend and verify every page loads without errors.

- Code comes over; **existing data does not**. The new backend starts empty — rows and uploaded photos in the original project stay there. If you need the data too, tell me and we can plan an export/import.
- The copy is one-way and one-time: this project will not stay in sync with future commits to that GitHub repo. For ongoing sync, connect this project to GitHub instead.
- This project's placeholder home page will be replaced by the repo's home page.

- Repo pins `@tanstack/react-router` 1.170.18 / `@tanstack/react-start` 1.168.32; I'll keep this project's template versions and adapt code if any API differs, rather than downgrading the stack.
